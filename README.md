Nurax AI is a DEX AI Agent that records and solves the anomalies on the device. It also allows users to solve their issues themselves without need of calling their IT Helpdesk.
At this moment, the focus is to build this tool for small & medium scale enterprises.

Some features:

1. Monitor device pulse
2. Check network issues
3. Check and auto solve known application issues
4. Let users ask the Agent to solve issues by posting images or text
5. Use the issues reported by the users to train the agent to be better
6. Device Performance Scores
7. Dashboard for admins to perform action (at a later stage, the admins will be obsolete)
